# 感知层设计（音频 → CW 文本）

> 状态：设计已锁定，待实现（阶段 1 baseline → 阶段 3 模型）。

## 总体形态：混合架构

并联两条通道，各做最擅长的事：

```
              ┌────────────────────────────────────────┐
  音频缓冲 ──▶│ DSP 旁路：Goertzel 扫频 → 估计           │──▶ 元数据
  (一段发报)  │   侧音频率 / SNR / WPM                   │   {freq, snr, wpm}
              ├────────────────────────────────────────┤
              │ 模型主路：窄带频谱图 → CRNN → CTC 解码    │──▶ 文本 + 字符置信度
              └────────────────────────────────────────┘
```

- **DSP 旁路** 产出物理量（频率/SNR/WPM），又准又便宜，喂给决策层（SNR 决定回复的 RST）。
  阶段 1 的 baseline 解码器复用为这条旁路，不白做。
- **模型主路** 只专注最难的事：从频谱图解出字符序列。CTC 后验概率兼作字符级置信度。

## 关键决策与理由

### 1. 输入表征：窄带频谱图（非 1D 包络）
CW 信息几乎全在"单一频率的能量随时间开关"，频率轴近乎退化。但仍选 2D 频谱图而非 1D 包络，
因为目标是**接真实电台**：模型看得见时频图才能自学跟踪频漂、在邻台(QRM)下挑出目标信号。
1D 包络法依赖"先锁对频率"，真实频漂/邻台下脆弱——放弃。

### 2. STFT 参数：短窗短跳步（与语音 ASR 相反）
CTC 靠时间分辨率区分点/划。40 WPM 时 dit 仅 30ms，若用语音常用的 25–32ms 窗会盖住整个 dit。
- 采样率 8 kHz
- 窗长 ~128 (16ms)，跳步 ~32–64 (4–8ms)
- 频率分辨率降到 ~60Hz 可接受：只需定位单峰，不需分辨谐波
- 取侧音附近窄频带（如 300–1100Hz）喂入 CNN

### 3. 网络结构：CRNN + CTC
几层 2D CNN（频率轴池化、时间轴适度下采样）→ 折叠频率 → 2 层 BiGRU → Linear → CTC。
目标参数量几十万~一两百万（"小模型"）。GPU(已确认 torch 2.11 + CUDA13) 上训练飞快。

### 4. 词表与 CTC blank
A–Z + 0–9 + 常用标点 + prosign(`<AR>`等) + **独立 space token** + CTC blank ≈ 50 token。
注意：CW 词间隔(7单位)有语义，space 必须是独立 token，不能与 CTC blank 混用。
模型学"长静音→space，短静音→不输出"——人手码间隔飘移正是模型碾压硬阈值法之处。

### 5. 解码时机：回合制缓冲（非真流式）
CW 通联是回合制。检测到一段发报结束（长静音 / 结束 prosign `<AR>` `<SK>` `K`）后，
把整段缓冲离线喂给模型。好处：可用双向 GRU（精度高）、工程简单。真流式留到阶段 4。

## 训练数据策略（CW 的超能力）

合成器(阶段0) + 增强管线 = 无限在线数据集。`Timeline` 提供逐元素标签。

增强随机维度（鲁棒性来源）：

| 维度 | 范围/方式 | 模拟 |
|------|-----------|------|
| WPM | 12–40 | 不同手速 |
| 人手抖动 | 每元素/间隔高斯扰动 + 系统性 dit/dah 比例偏置 | 个人 fist |
| 侧音频率 | 400–900Hz + 缓慢漂移 | VFO 漂移/调谐不准 |
| 加性噪声 | 白/粉红/脉冲，SNR −5~+20dB | QRN |
| QSB | 低频乘性包络 | 电离层衰落 |
| QRM | 偶尔叠加第二个弱 CW 信号 | 邻频干扰 |

文本分布要拟真：呼号 / RST / QSO 话术模板混合，非纯随机字母（让模型学到 "599" 等高频先验）。
后期混入真实录音(RBN/LCWO/WebSDR)做微调与域适应。

## 评测

- 用阶段 1 DSP baseline 作对照组：在同一批合成数据（分 SNR/手速分桶）上比字符错误率(CER)。
- 没有 baseline 就无法证明模型的价值——baseline 是必需品，不是临时占位。
